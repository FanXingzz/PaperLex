# PaperLex · 详细使用说明

本轮更新：阅读器 50%–200% 缩放、右栏 12–22px 字号、继续阅读与页内位置记忆、双语多义项词典和朗读、项目术语约束翻译，以及更清晰的学术文本排版。翻页 / 连续滚动与文本精读 / PDF 原版仍可组合使用。

源码仓库：[FanXingzz/PaperLex](https://github.com/FanXingzz/PaperLex)。首次从仓库下载时请保留完整目录结构，双击启动脚本会按需安装依赖。仓库不包含个人论文、数据库、密钥或模型。

这是在自己电脑上运行、通过浏览器操作的科研文献阅读软件。浏览器只是操作窗口；文献、笔记和学习记录保存在电脑上的 `data` 文件夹。打开本地地址不等于把文献上传到网站。

第一次使用建议走这条路线：**启动 → 新建项目 → 开启普通联网 → 导入一篇论文 → 选词查询 → 收藏 → 复习**。无需先安装模型，也无需先填写任何密钥。

## 1. 正确启动、关闭和更新

1. 打开 `E:\研究生\文献软件`，双击 `启动.bat`。
2. 启动窗口会打印中文提示，并自动打开默认浏览器。正常情况下进入 `http://127.0.0.1:3089`。若该端口被其他程序占用，会使用后续端口，以窗口实际显示为准。
3. 如果浏览器没有自动打开，把窗口中的完整地址复制到浏览器顶部地址栏，再按回车。不要把地址放进搜索框。
4. 使用期间保留最初的启动窗口，可最小化。仅关闭网页不会停止软件；下次可重新访问同一地址。
5. 结束使用时关闭启动窗口，或在窗口中按 Ctrl+C。再次使用时重新双击脚本即可。
6. 如果重复双击，启动器会尝试打开同一数据目录已经运行的新版软件，不会重复启动它。

**本次修复了什么：**原脚本含中文内容、采用 LF 换行，在你的 Windows 命令窗口中出现乱码和命令截断。现改为纯 ASCII 的短批处理入口、Windows CRLF 换行，中文提示由 Node.js 启动器输出，并自动打开浏览器。

**更新后仍看到旧界面：**关闭之前运行软件的终端窗口，再运行新版 `启动.bat`，在网页中按 Ctrl+F5。不要删除 `data`，也不需要重新导入文献。本次两种阅读模式的更新作用于已有文献。

需要 Node.js 22.13 或更高版本。本文件夹已有依赖时，可断网启动；如果依赖缺失，首次安装 PDF 组件需要联网。启动环境安装与软件内的“联网服务”开关是两件事。

软件左下角“使用指南”可打开本教程；软件没启动时，也可直接双击同目录的 `详细使用说明.html` 阅读，教程本身不需要联网。

## 2. 三种主要使用模式怎么选

| 能力 / 设置 | 纯离线 | 普通联网（先用这个） | 离线 + 本地模型 |
| --- | --- | --- | --- |
| 启用联网翻译与科研语料检索 | 不勾选 | 勾选 | 不勾选 |
| 启用模型增强释义与双语概要 | 不勾选 | 不勾选 | 勾选并配置 |
| 本地文献阅读、连续滚动、批注 | 可以 | 可以 | 可以 |
| 在自己的文献库找同词例句 | 可以 | 可以 | 可以 |
| 收藏、编辑词汇、间隔复习 | 可以 | 可以 | 可以 |
| 未收录单词与句子自动翻译 | 不可以，可手动填释义 | MyMemory 在线翻译 | 本机模型生成 |
| 联网搜索其他科研论文 | 不可以 | OpenAlex 检索 | 不可以；需另开联网 |
| 自动英文概要 | 原文关键句摘录 | 原文关键句摘录 | 模型生成概要 |
| 自动中文概要 | 无，显示待生成 | 英文摘录的机器翻译 | 模型生成概要 |
| 是否需要模型安装或模型密钥 | 不需要 | 不需要 | 需要安装本地模型，通常无需密钥 |

右上角的“离线模式 / 联网服务已启用”只表示开关状态，并不代表已经检测网络通畅。设置会保存在本机，关闭再打开仍会保留。

## 3. 普通联网：最简单的配置方法

1. 确保电脑可以正常上网，启动软件。
2. 点击左下角 **设置与数据**。窗口较窄时，它是左侧齿轮图标。
3. 勾选 **启用联网翻译与科研语料检索**。
4. **OpenAlex API Key（可选）先留空**。它用于科研论文检索，不用于普通翻译。
5. **不要勾选“启用模型增强释义与双语概要”**。下面的服务地址、模型名称和模型 API Key 保持原样即可，它们在此模式不会使用。
6. 不要勾选“清除已保存的全部密钥”。点击窗口底部 **保存设置**。
7. 右上角应显示 **联网服务已启用**。进入一篇文献，在右侧输入 `electric field`，点击 **查询释义**。
8. “electric field”已被内置科研词库收录，显示“电场”不能单独证明联网成功。进一步选择“句子：翻译完整句子”，输入 `The electric field increases during the discharge.`，成功时可见全句译文及 MyMemory 来源。检查结果下方是否有错误信息。

各在线服务分工：MyMemory 翻译词句、词典英文释义与摘录；Free Dictionary API 提供英文义项、音标及可用发音；OpenAlex 检索科研论文元数据和公开摘要。一项失败不代表另一项一定失败。网络环境、服务额度及接口要求都会影响可用性。

### 3.1 联网查词和长句翻译

1. 打开文献，把鼠标放在中间原文区域，拖选同一页内的英文词、短语或句子。
2. 点击浮动工具条里的 **查词 / 翻译**。也可直接在右侧输入框粘贴英文，再点击 **查询释义**。
3. 右侧释义框可手动修改。专业术语有歧义时，应根据课题核对、补充。
4. 点击 **收藏并加入复习**，会保存所选文本、释义、来源页和上下文。同一项目中再次收藏相同词条会更新内容，而不是再建一个重复条目。

本轮词语结果分为：读音与音标、当前语境释义、不同义项的中英文解释、对应双语例句，以及本地和联网论文例句。内置科研词条按原句与课题线索排列义项，例如 plasma 的等离子体 / 血浆、quenching 的猝灭 / 淬火。每张义项卡都会标注来源；教学例句不是论文引文。

普通联网模式会为未内置的单词查询 Free Dictionary API，并翻译可用的释义与例句。最多展示 4 条在线词典义项；词典缺少例句或音标时明确显示缺失，不编造。外部词典是通用英文词典，不能覆盖全部科研词汇。联网后查询词会发送给该词典，播放词典音频时浏览器会访问音频来源。

点击“读音”或“例句读音”可朗读英文，优先使用可用的系统英文语音；联网且系统无合适语音时尝试词典音频。离线只使用本地语音。若没有声音，检查音量与 Windows 已安装的英文语音；音标可见不代表电脑必然已安装发音资源。

查询输入框下可手动选择“词语”或“句子”。句子模式显示**全句翻译**，不会把每个词拆成词卡。自动识别有局限，短句误判时手动切换即可。单次最多 4000 字符，较长内容建议分句；跨页请分段选取。

普通翻译已增加科研术语约束，但仍是通用翻译引擎，不能保证复杂句法和专业歧义完全准确；有兼容模型时启用模型增强，可同时利用原句、研究方向、术语表和本地例句生成解释。

### 3.4 校正项目专用术语，让后续翻译保持一致

在词语结果下展开“校正为本项目的专业译法”，填写简短译法，例如 quenching → 猝灭，点击保存。后续同项目查词优先展示该译法；模型整句翻译会收到这些术语约束。普通翻译先翻译完整英文句子，再把可识别的中文译词校正为项目指定译法，以保留句子语序。不能自动识别的译词仍需人工核对；请只填写术语，不要填整段解释。

在“我的词汇库 → 项目专用术语”中可以查看或删除校正。它与用于复习的收藏词条相互独立，删除一个不会自动删除另一个。术语表随数据备份与 JSON 导出保存。

### 3.2 查找课题相关论文里的例句

1. 新建项目时，在研究方向栏填简洁英文关键词，例如 `plasma electric field diagnostics`。不填时，系统会从项目文献关键词中补充检索条件。
2. 在阅读页查一个词，例如 `electric field` 或 `quenching`。
3. 查词后，短词和短语会自动发起论文检索。点击右侧 **联网论文语料** 标签查看结果；也可点击其中的 **检索科研论文** 手动发起。
4. 系统显示检索条件、论文标题、年份、来源链接，以及公开摘要中确实包含该词的句子。点击标题可去论文来源网页。
5. “元数据相关，但公开摘要未提供该词的完整例句”表示只找到了相关论文信息，不是已经取得了全文用例。没有结果也不代表没有相关论文。

检索以项目方向辅助匹配，不是对课题的深度自动理解；也不是无限制全文下载器。当前界面尚无项目重命名 / 编辑方向入口，方向填写不合适时可另建项目并重新导入所需文献。

如果论文检索提示认证或额度问题，可在 [OpenAlex 官方页面](https://openalex.org/)登录，按其账户页面指引获取个人 API Key，再填入设置对应框。已有密钥时，密码框留空保存会保留旧密钥。密钥和额度要求以 [官方认证说明](https://help.openalex.org/api/authentication/)为准。

### 3.3 获得中英文概要

1. 先开启联网并保存，再导入文献：程序自动摘取英文关键句，再翻译为中文。
2. 如果文献早已在离线状态下导入，打开它，在右侧 **文献双语概要** 中点击 **重新生成**。仅切换联网开关不会批量重做以前的概要。
3. 等待状态从“正在生成…”变为“双语概要已就绪”。通过 **中文概要 / English** 切换语言。
4. 右侧内容较多时，把鼠标移到右侧栏内滚动，概要可能位于查词和例句下方。
5. 如果出现“译文待重试”，查看错误原因，恢复网络或等待额度恢复后再点击重新生成。

普通联网模式是“原文摘录 + 中文翻译”，不是逐项分析整篇论文。更详细的研究问题、方法、发现和局限概要需要配置模型。模型也只接收前 26000 字符，长文后半部分的信息可能遗漏。

## 4. 完全离线怎么用

1. 打开设置，取消勾选“启用联网翻译与科研语料检索”和“启用模型增强释义与双语概要”，保存。
2. 新建项目，导入文献，阅读原文、滚动页面、批注，均不需要网络。
3. 输入词汇后点 **本地关联**，可找出项目内含此词的句子。勾选 **检索整个本地文献库** 可跨项目查找。
4. “词形匹配”尝试识别常见变化，例如 field / fields；“精确匹配”只匹配原词形、不区分大小写。短语必须在一个完整句子中按顺序出现。
5. 点击例句的 **回到原文** 跳到对应文献页。离线无模型时，“解释此句”无法生成新的译文；原文例句仍可看。
6. 内置词库仅有少量通用和等离子体相关术语，其中一部分已扩展为含音标、多义项和双语教学例句的结构化词条，并不是完整离线字典。未收录词可以手填释义或配置本地模型。
7. 已收藏词汇、已生成的中文概要、批注和复习计划仍能离线查看。没有收藏的在线查询结果和论文检索结果不构成永久离线缓存。

关闭联网开关不会删除以前的中文概要，也不会把数据库清空。纯离线导入的新文献只有英文摘录，中文待生成是预期状态。

## 5. 离线也想自动翻译：配置本地模型（可选）

如果只是想先使用联网翻译，可以跳过本节。本软件不附带模型，不会因为勾选模型开关就自动安装模型。

1. 从 [Ollama Windows 官方下载页](https://ollama.com/download/windows)下载并安装 Ollama。保持它运行。
2. 在 Windows 搜索中输入 PowerShell，打开后输入以下命令，按回车：

```text
ollama pull qwen2.5:7b
```

首次下载需要联网、磁盘空间和时间；运行所需资源取决于模型和电脑配置。这里给的是与默认填写值一致的示例，不保证每台电脑都能快速运行。

3. 下载完成后输入 `ollama list`，确认列表中有 `qwen2.5:7b`。可用 `ollama run qwen2.5:7b` 先尝试问一句话；输入 `/bye` 离开对话。
4. 回到 PaperLex → 设置与数据，按下表填写：

| 设置项 | 填写内容 |
| --- | --- |
| 启用联网翻译与科研语料检索 | 若想离线使用，取消勾选 |
| 启用模型增强释义与双语概要 | 勾选 |
| 服务地址 | `http://127.0.0.1:11434/v1` |
| 模型名称 | `qwen2.5:7b`，必须与本机实际模型名一致 |
| 模型 API Key | Ollama 本机服务通常可留空；如原来存过远程密钥，可先清除 |
| OpenAlex API Key | 与本地模型无关，不需要填写 |

5. 点击保存，进入文献查词，或点击概要的重新生成。成功时释义来源显示“模型语境解释”，概要来源显示模型双语概要。
6. 模型已下载完成、选择的是本地模型且服务正常运行时，推理可在本机完成。不要选云端模型来代替这里的本地模型，云端模型仍可能联网发送文本。

服务地址的 `11434` 是模型服务端口；`3089` 是文献软件页面端口，两者不能混填。服务地址应停在 `/v1`，不要再加 `/chat/completions`。本软件会自动补上请求路径。

当前单次外部请求超时约 45 秒；本地模型首次加载或电脑算力不足可能超时。可以先在 Ollama 中预热模型，改用适合本机的更小模型并同步修改名称，或先关闭模型增强使用普通联网。模型返回格式不符合要求时，中文概要会提示失败，不会假装完成。本机尚未预装、实测本地模型，本节是配置教程。

本地服务配置依据 [Ollama 官方接口文档](https://docs.ollama.com/api/openai-compatibility)；示例模型见 [官方模型页](https://ollama.com/library/qwen2.5:7b)。

## 6. 远程模型与混合模式（进阶，可跳过）

如果你已有支持 Chat Completions 格式的远程模型服务，可同时勾选联网与模型增强，并填写服务方提供的基础地址、实际模型名称和 API Key。地址不是网页聊天地址。软件不提供模型账号或额度，费用由服务方决定。

启用模型增强后，查词和概要优先使用模型。词句查询遇到模型失败时，会明确提示并尝试内置词条或联网基础翻译；未联网时不能回退到在线服务。文献概要的模型任务失败仍需修复配置后点击重新生成。想固定使用普通翻译，可取消模型增强、保持联网开启并保存。

同时开启联网 + 本地模型时，词句解释和概要由本地模型完成，论文检索仍联网访问 OpenAlex。开启联网 + 远程模型时，所选上下文和用于概要的文献片段会发送到该远程模型。

## 7. 项目、导入、连续滚动与批注

### 7.1 建项目并导入

点击“新建项目”，名称可以写“低温等离子体电场诊断”，研究方向建议用简短英文。创建后选择左侧项目，再点击“导入文献”，或把文件拖到文献列表区域。处于“全部文献”且有多个项目时，要先选择导入目标项目。

支持 PDF、UTF-8 TXT 和 Markdown，可一次多选；单文件最大 50 MB，PDF 最多 1000 页。同一项目内按文件内容去重，改文件名不会绕过去重。软件复制文件到自己的数据目录，不修改外部原件。导入时文件名去掉扩展名作为文献标题。

### 7.2 翻页模式与连续滚动：可以自由切换

打开文献后，原文顶部有两组独立选项。第一组是**文本精读 / PDF 原版**，决定内容怎样呈现；下面“阅读方式”一栏是**翻页模式 / 连续滚动**，决定怎样翻页。两组可以自由组合，切换时保留当前页。

**翻页模式：**每次只显示一页，通过顶部上一页 / 下一页按钮切换。滚轮只在当前页面内移动，不会直接切到下一页。适合对照版式、逐页精读。

**连续滚动：**把鼠标放到中间原文区域，滚动鼠标滚轮或触控板，即可从第一页连续读到后续页。每页之间有页码分隔，顶部页码随滚动更新。适合顺着全文阅读。

初次默认为连续滚动；你选过“翻页模式”后，同一浏览器、同一本地地址会记住偏好。重启软件后一般不用重新选，清理浏览器站点数据、换浏览器或换端口可能重置偏好。

- **文本精读**：展示提取文字，适合查词、检索和准确记录高亮批注；翻页模式只呈现当前页，连续模式纵向排列全部页。
- **PDF 原版**：保留原始版式；连续模式靠近可视区域时逐步加载，长文不会一次渲染全部画布。
- **上一页 / 下一页**：两种阅读方式都可用；翻页模式切换页面，连续模式直接滚动到相邻页。
- 在两种模式之间切换，会定位到当前页。批注和例句的“回到原文”也会定位到对应页。
- 如果滚动的是右侧释义栏，移动的是右侧内容；请把鼠标移到中间论文上再滚动。
- 跨页选区暂不支持直接批注或查询，请在同一页内分段选择。

### 7.3 批注与收藏是两回事

拖选同一页中的原文 → 点击“批注” → 填笔记 → 选颜色 → 保存。黄色可记重点，绿色可记方法，紫色可记疑问。右侧“阅读批注”中可看笔记、回到页码或删除。精读模式显示原文高亮；批注保存在软件数据库，不写回 PDF 文件。

“收藏并加入复习”用于词汇记忆，不会自动生成阅读批注。若两者都需要，可以分别执行。PDF 原版选区不能精确匹配提取文字时，会提示切换文本精读；它不是批注已成功。

### 7.4 原文缩放与右栏字号

原文顶部有“− / 百分比 / ＋ / 重置”，范围为 50%–200%；鼠标放在原文内，按住 Ctrl 滚动也可调整。PDF 按比例重新渲染，放大后可在中间阅读器内横向滚动；文本精读调整字大小并重新排版。重置恢复 100%（PDF 适合当前阅读宽度）。

右栏顶部有独立的“右栏字号 A− / A＋”，范围 12–22px。调整影响释义、例句、概要和批注，不会同时缩放原文。两个设置在当前浏览器中保存。

### 7.5 从其他页面回到正在读的论文

左侧“继续阅读”按钮显示最近打开的文献与页码。从词汇库、复习页或其他项目切走后，点击它即可返回最近文件。软件记录页码、页内相对位置及文本 / PDF 显示方式；刷新页面后也可使用该入口，不必重新找文件。

阅读位置保存在当前浏览器的本地存储，最多保留最近 30 篇记录；切换浏览器、清理站点数据或使用不同端口可能看不到原阅读进度。文献、批注和词汇仍保存在数据库，不受此影响。该按钮指向最近打开的文献，不是无限历史后退。

### 7.6 文本精读排版与旧文献优化

精读模式使用较舒适的行宽、段间距，并区分标题、摘要及小节、正文与参考文献条目。排版保留原始文字节点顺序，已有批注不会因为增加段落样式而错位。新导入 PDF 会按文字坐标重建阅读顺序，对常见双栏版式做按列排序，减少同一行左右栏被拼接的问题。

已有 PDF 可在阅读页顶部点击“优化文字提取”，按新版方式重新解析。可以唯一匹配的批注会迁移到新位置；有重复选区或无法匹配的页保留旧文本，并提示页码。不会修改 PDF 原件，也不会删除笔记。复杂表格、公式、跨栏插图及扫描件仍需结合 PDF 原版核对；此功能不是 OCR，也不保证自动还原全部版面。

## 8. 词汇库与记忆复习

1. 阅读时查询或手填释义，点击收藏。没有释义的词条不能保存。
2. 左侧“我的词汇库”可以按单词或中文搜索，编辑释义，删除词条，点击“原文”返回出处。显示范围与所选项目有关，选“全部文献”后可查看全部项目词条。
3. 点击“今日复习”，先看词和原句，尝试回忆；按空格或点“显示释义”翻卡。
4. 自评“忘记了 / 有点难 / 记住了 / 很熟悉”，快捷键分别为 1 / 2 / 3 / 4。
5. 新词立即进入待复习队列。忘记后约 10 分钟再次到期；首次记住后约 1 天、下一次约 3 天；首次很熟悉约 4 天。后续随历史自评调整。
6. “当前没有到期词汇”可能只是下一次复习尚未到，不代表词汇被删除。应用关闭期间不会弹出系统复习提醒，打开后再查看队列即可。

当前使用 SM-2 风格的间隔重复调度，没有自定义整套遗忘曲线参数的界面，也不是完整的百词斩产品复刻。间隔依据自评调整，不保证固定记忆效果。

## 9. 常见问题排查

| 看到的现象 | 处理办法 |
| --- | --- |
| 双击脚本出现乱码、“不是内部或外部命令” | 使用本次更新后的启动.bat；关闭旧窗口后重新运行，不要从聊天里复制脚本覆盖它 |
| 浏览器提示无法访问本地地址 | 确认启动窗口仍在运行，使用它显示的实际地址，而不是固定猜测 3089 |
| 更新后 PDF 仍只能逐页看 | 原文顶部“阅读方式”选择连续滚动；看不到切换栏时关闭旧服务、重新启动，网页按 Ctrl+F5 |
| 中文概要尚未生成 | 检查联网或模型是否启用并保存，再到该文献点重新生成 |
| 在线只有内置释义，没有新翻译 | 查看来源和错误文字；模型未配置时关闭模型增强；只打开联网开关 |
| 提示 fetch failed、超时、服务不可用 | 对应外部服务未连通；检查网络或模型是否运行，稍后重试。不是文献丢失 |
| 401 / 403 或认证失败 | 检查服务对应密钥、地址和权限；OpenAlex 密钥与模型密钥不可混填 |
| 429、额度耗尽 | 暂停请求，等待或按提供方说明处理额度；软件不会自动购买额度 |
| 模型 404 或模型不存在 | 核对基础地址停在 /v1，模型名称与实际安装或服务支持名称一致 |
| 扫描 PDF 没有文字 | 先用 OCR 工具识别后再导入；本软件不含 OCR 引擎 |
| PDF 文本顺序乱、公式不完整 | 切换 PDF 原版核对；多栏、表格、公式提取可能不准确 |
| 本地例句找不到 | 确认项目范围，尝试全库或词形匹配；仅检索成功提取的文字 |
| 右侧看不到概要 / 批注 | 在右侧栏内部向下滚动，联网例句可能占据较长区域 |

MyMemory 有字符和调用额度限制；具体以 [官方额度说明](https://mymemory.translated.net/doc/usagelimits.php)为准。本程序未提供 MyMemory 邮箱等高级额度配置入口。论文检索、翻译、远程模型可能适用不同额度。

## 10. 数据保存在何处、怎样备份

所有项目、文献解析文本、笔记、词汇、复习记录、概要和设置保存在 `E:\研究生\文献软件\data`。原文件副本位于其中的 `files` 子目录，数据库为 `paperlex.sqlite`。

完整备份：停止软件 → 复制整个 `data` 文件夹到安全位置。迁移电脑时，目标电脑需有运行环境和软件文件，再在软件关闭状态下放回完整数据文件夹。恢复会使用备份的数据，不会自动与另一份数据合并；先保存目标端现有数据副本。

“设置与数据 → 导出学习数据”得到可读 JSON，包含学习记录和提取文字，不含 PDF 二进制与密钥。当前没有导入 JSON 恢复按钮，因此它不能代替完整 `data` 备份。不要删除 `data` 来处理启动问题，不要只拷贝运行中的单个 SQLite 文件。

纯离线时，不向上述翻译或论文服务发出请求。普通联网会发送查词内容、自动摘录和检索关键词；远程模型会接收所选上下文和用于概要的文献片段。原 PDF 文件不会直接上传。应用不嵌入远程页面，点击论文来源链接会在浏览器访问外部网站。

双击 `启动.bat`，在浏览器打开终端显示的地址（默认 http://127.0.0.1:3089）。需要 Node.js 22.13+；首次缺少依赖时启动脚本会安装依赖。此目录已经安装好依赖。

## 使用流程

1. 新建研究项目，填写名称和研究方向。推荐用英文写关键词，提高科研论文检索相关性。
2. 选择该项目，导入或拖入 PDF、UTF-8 TXT、Markdown，可多选。单文件上限 50 MB、PDF 上限 1000 页。同一项目内按文件内容去重。
3. 打开文献，在“文本精读”中选中单词、短语或句子，查词翻译或批注。PDF 原版支持原始布局、逐页阅读与选词；若选区无法与提取文字精确对齐，在文本精读中批注。
4. 查询结果提供可编辑的释义、项目内完整例句；可改为整个本地文献库及精确匹配。例句支持回到原文页和逐句解释。词形匹配采用轻量英文规则，并非完整语言学词元分析。
5. 收藏词句时保留科研释义、上下文、来源文献和页码。词汇库支持搜索、编辑、删除和回到原文。
6. “今日复习”先展示词与语境，翻卡后自评。遗忘 10 分钟后再见；正常学习初始间隔 1 天、3 天，后续按难度增长，熟悉初始 4 天。使用 SM-2 风格间隔调度，并非精确拟合个体遗忘曲线。

## 翻译、科研语料与双语概要

默认完全离线：文献导入、阅读、批注、全文句子检索、内置约 30 条科研术语、英文关键句摘录及词汇复习可用。内置术语仅为少量通用与等离子体术语，不是完整科研词典。

在“设置与数据”中开启联网服务：

- MyMemory 翻译所选英文词句；中文概要由自动抽取的英文概要翻译得到。免费服务有额度限制，无法保证专业术语精度。
- OpenAlex 使用查询词 + 项目研究方向（未填写时使用导入文献关键词）检索相关论文，返回公开元数据与可用摘要。只有真实摘要中匹配的完整句子才作为例句呈现；无摘要不伪造语料。可选填 API Key；服务认证与额度以提供方当前要求为准。
- 对短词／短语查词后自动加载科研论文语料，较长句子可手动检索。
- 上传文献后自动生成概要；离线时保留英文摘录，并明确标示中文待生成。开启服务后，已有文献需点击“重新生成”。

可在设置连接 Chat Completions 兼容模型：本机服务地址例如 `http://127.0.0.1:11434/v1`，模型名称必须是你实际安装的模型名称。使用本机模型不必启用联网。软件不附带模型权重，也不自动安装模型。模型可提供课题语境释义和中英文研究概要（研究问题、方法、结果与局限），最多输入文献前 26000 字符，因此长文可能遗漏后文内容。界面会标注摘要来源和处理失败信息。

联网功能的请求会发送所选文本、概要摘录与课题关键词；远程模型概要会发送上述文献片段。不会发送原 PDF 文件。不要向外部服务发送不宜公开的研究资料；可以使用本机模型。密钥保存在本机 SQLite 中，不在浏览器响应或学习数据导出中返回。

## 数据与备份

- `data/paperlex.sqlite`：项目、解析文本、批注、词汇、概要、设置和复习记录。
- `data/files/`：导入文件的本地副本，使用随机标识命名；不会修改你的原始文件。
- “导出学习数据”导出可读 JSON（含文献提取文本、批注、词汇、复习记录，不含密钥及 PDF 二进制）。当前没有 JSON 恢复入口。
- 完整备份和迁移：停止软件后复制整个 `data` 文件夹；恢复时停止软件，将备份的 `data` 放回程序目录。不要只复制运行中的单个 SQLite 文件。
- 服务仅监听 `127.0.0.1`，校验 Host 与 Origin，拒绝跨站请求；不对局域网开放。

## 已知限制

扫描版 PDF 需要先用 OCR 工具识别；当前不包含 OCR 引擎。PDF 多栏、公式、表格文字的提取阅读顺序可能与视觉版式不同，请结合 PDF 原版核对。批注锚定页内提取文本，保存在应用数据库，不直接写回 PDF 文件。内置语料仅来自用户导入文件，联网语料主要为公开摘要，不承诺取得论文全文。机器翻译及模型解释应结合原文核对。

前端采用原生 HTML/CSS/JavaScript，后端采用 Node.js HTTP + SQLite，PDF.js 完成本地 PDF 文字提取和浏览器渲染。无需云端账号即可使用离线功能。默认端口占用时尝试后续端口（至 3100），以控制台实际输出为准。可通过 `PORT` 与 `PAPERLEX_DATA` 指定端口和数据目录。
