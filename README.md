# PaperLex

**本地科研文献阅读、语境查词、全文翻译与词汇复习工具。**

PaperLex 将 PDF 阅读、科研词汇学习和论文翻译放在同一个工作空间：按课题建立项目，在原版论文中选词、批注，结合本地文献查用法，再通过间隔复习巩固词汇。

应用在自己的电脑上运行，通过浏览器操作。离线阅读与查词无需云端账号；GPT、DeepL、其他兼容模型和论文检索服务按需配置。

[快速开始](#快速开始) · [翻译服务配置](#翻译服务配置) · [详细使用指南](docs/使用指南.md) · [本机模型指南](本机模型使用说明.md) · [问题反馈](https://github.com/FanXingzz/PaperLex/issues)

## 核心功能

| 功能 | 当前实现 |
| --- | --- |
| 项目与文献库 | 按研究课题建项目，导入 PDF、UTF-8 TXT、Markdown；项目内文件去重 |
| 原版 PDF 阅读 | 翻页／连续滚动切换、缩放、右栏字号调整、记住阅读位置、收起顶部工具区 |
| PDF 批注与定位 | 直接选文批注，红色单下划线；点击批注返回原位置 |
| 语境查词 | 本地英汉词典、音标、科研术语、可编辑释义；按需补充双语义项与例句 |
| 词汇收藏 | 收藏词黄色高亮，保存原句与 PDF 位置；修改释义后保存，下次查询保留 |
| 本地文献关联 | 在当前项目或整个本地库检索同词例句，支持词形匹配与返回原文 |
| 全文翻译 | GPT／兼容模型、DeepL、MyMemory；自动排版、原页对照、逐段校对保存 |
| 原译文联动 | 点击译文段落高亮对应原文，切换段落后清除上一处高亮 |
| 翻译任务管理 | 暂停／继续、失败段重试、1–2 段并行、已完成内容保留与基础翻译缓存 |
| 译稿导出 | 版式 HTML、可编辑译稿 JSON、浏览器打印 PDF |
| 遗忘曲线复习 | 自评调整复习间隔，显示估计记忆率，支持调整目标记忆率 |
| 联网论文语料 | Europe PMC、OpenAlex、Semantic Scholar；支持部分开放正文的例句检索 |
| 双语概要 | 离线英文摘录；联网翻译摘录；模型增强研究问题、方法、结果和局限概要 |

本地资源包含约 **76.9 万条 ECDICT 英汉词条**、英美音标库，以及通过依赖安装的 WordNet 英文义项。通用词典不能替代专业判断；可用项目术语表统一课题译法。

## 快速开始

### 环境要求

- Node.js **22.13 或更高版本**，使用自带 SQLite 能力。
- 现代浏览器，建议使用 Chrome 或 Edge。
- Windows 提供双击启动入口；其他系统可使用命令行启动，尚未完成同等范围的界面验证。
- 首次安装依赖需要网络。应用不附带模型权重，也不自动安装模型。

### Windows 双击启动

1. 下载仓库 ZIP 并完整解压，或克隆本仓库。
2. 安装符合版本要求的 Node.js。
3. 双击项目根目录的 **启动.bat**。缺少依赖时，启动器会尝试安装。
4. 浏览器自动打开本地地址，默认 `http://127.0.0.1:3089`；端口占用时以启动窗口输出为准。
5. 使用期间保持启动窗口运行。结束使用时关闭窗口或按 Ctrl+C。

### 命令行启动

```sh
git clone https://github.com/FanXingzz/PaperLex.git
cd PaperLex
npm ci
npm start
```

`npm start` 启动服务后，在浏览器打开终端输出的地址。Windows 自动打开浏览器、依赖检查等由 `启动.bat`／`launcher.mjs` 提供。

### 第一次阅读

1. 新建项目，填写名称和研究方向；英文关键词有助于论文检索。
2. 导入论文，打开 PDF，选择翻页或连续滚动。
3. 拖选单词或句子，点击“查词 / 翻译”，或直接添加批注。
4. 编辑释义后点击收藏／保存按钮，将词义、完整语境与来源位置存到本机。
5. 在“我的词汇库”回到原文，在“今日复习”进行翻卡自评。

导入限制：单文件最大 50 MB，PDF 最多 1000 页。扫描件需先进行 OCR；软件没有内置 OCR 引擎。

## 翻译服务配置

在 **设置与数据** 中配置，点击保存后再测试连接。模型与 DeepL 的密钥分别保存，全文翻译页面可手动选择来源。服务失败时不会自动把论文切换发送给另一家服务。

| 方式 | 所需配置 | 使用范围 |
| --- | --- | --- |
| 纯离线 | 无需密钥，关闭联网和模型增强 | 阅读、批注、本地词典、关联与复习；不生成新的全文译文 |
| 本机模型 | 启动 Ollama 等兼容服务，填写地址与已安装模型名 | 语境解释、概要、全文翻译；可关闭联网 |
| OpenAI GPT | 联网、模型增强、API 密钥及可用模型 | 语境解释、概要、全文翻译 |
| 自定义远程模型 | 联网、兼容 Chat Completions 的地址、模型名和密钥 | 同上，取决于服务能力 |
| DeepL API | 联网、API Free／Pro 套餐和独立密钥 | 全文翻译；无需启用模型增强 |
| MyMemory | 开启联网，可选填写真实联系邮箱 | 基础词句翻译、词典解释翻译、摘录与全文翻译备用 |

### OpenAI GPT

1. 模型预设选择 **OpenAI GPT**，自动填写 `https://api.openai.com/v1` 和示例模型 `gpt-4.1-mini`。
2. 填写自己的 OpenAI API Key，确认启用联网及模型增强，然后保存。
3. 重新打开设置，点击“测试已保存的模型连接”。测试只发送一句内置示例。
4. 全文翻译来源选择 **GPT / 已配置模型**，点击开始。

模型名可修改为账号可用且支持 Chat Completions 的文本模型。软件使用 API 密钥与对应额度，不读取 ChatGPT 网页登录会话。密钥仅在本机设置中填写。更换模型服务器时不会沿用旧服务器密钥。

官方入口：[API 密钥](https://platform.openai.com/api-keys)、[示例模型文档](https://developers.openai.com/api/docs/models/gpt-4.1-mini)。

### DeepL

1. 准备 DeepL **API** 账号的密钥，在设置中选择匹配的 API Free 或 API Pro。
2. 开启联网，填写 DeepL API Key 并保存。
3. 点击“测试已保存的 DeepL 连接”。
4. 全文翻译来源选择 **DeepL API · 联网翻译**，开始任务。

DeepL 的配置用于全文翻译，不会自动替换所有查词或概要服务。配额与费用以自己的 API 套餐为准，普通网页订阅不能代替 API 密钥。鉴权失败时先核对密钥与 Free／Pro 选择。

官方说明：[API 套餐](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans)、[翻译接口](https://developers.deepl.com/api-reference/translate/request-translation)。

### 本机模型

安装并启动 Ollama 后，下载模型，例如：

```sh
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```

在 PaperLex 启用模型增强，填写地址 `http://127.0.0.1:11434/v1`、模型名 `qwen2.5:7b`，本机 Ollama 通常无需密钥。模型需要另行下载，速度取决于硬件；示例模型不是所有电脑的最佳选择。

从安装到排错的完整步骤见 [本机模型使用说明](本机模型使用说明.md)。

### MyMemory

开启联网即可使用，不需要本机模型。公共服务有字符额度与频率限制，较适合短句或备用；不能保证满足每日多篇论文全文翻译。在设置填写真实联系邮箱可按服务方规则获得不同额度。成功结果本地缓存，请求串行发送，遇到限流暂缓请求。

## 全文翻译工作流

1. 阅读页打开“全文翻译与编辑”，选择已配置的服务。
2. 点击开始，按需要选择 1 或 2 段并行。慢速本机模型建议先用 1 段。
3. 左侧保留原版论文图像，右侧译文自动换行。点击译文可定位并高亮对应原段。
4. 在“逐段校对”中修改译文，点击保存或 Ctrl+S；可将公式等内容标为保留原文。
5. 导出 HTML、JSON 或通过浏览器打印保存 PDF。

顶部支持收起／展开；原页支持整页、适合宽度和缩放，放大后可独立滚动。导出保留原页参考图与完整译文，不承诺逐字原位替换版式。人工修改不会被在途翻译覆盖；失败后可继续处理未完成段落。

## 科研语料与复习

- **本地语料**：查词后选择“本地关联”，可切换项目内或全库范围。例句来源于已导入文献的可提取文字。
- **联网语料**：选择论文引擎并点击检索。摘要结果与正文结果分开标示；支持 Europe PMC 可获取的正文 XML 和识别到的 arXiv PDF。其他来源可合法下载后导入。
- **概要**：导入时生成；修改服务设置后，已有论文需手动点击“重新生成”。模型概要最多使用文献前 26000 字符。
- **复习**：使用指数遗忘曲线和自评调整记忆稳定性，并按目标记忆率安排间隔。该模型是学习安排工具，不是个人记忆能力的精确测量。

## 数据、隐私与备份

| 路径 / 导出 | 内容 |
| --- | --- |
| `data/paperlex.sqlite` | 项目、解析文本、词汇、批注、概要、译稿、复习记录及设置 |
| `data/files/` | 导入原文件的本地副本 |
| 学习数据 JSON | 学习记录、提取文字与译稿；不含密钥和 PDF 二进制 |

- 服务仅监听本机 `127.0.0.1`，不面向局域网或公网部署。
- 关闭联网并使用本机模型时，论文内容由本机处理。
- 联网查词、论文检索、概要和全文翻译会按功能发送相应文字、研究方向或检索词。全文翻译逐段发送可提取文字，不直接上传原 PDF 文件。
- 密钥保存在本机 SQLite，未进行应用层加密；设置响应与学习数据导出不会回传密钥。
- 完整备份：**停止软件后复制整个 `data` 文件夹**。迁移时在软件停止状态下恢复，先备份目标端已有数据。
- JSON 导出不能代替完整备份，当前没有学习数据 JSON 导入恢复入口。

仓库不包含个人论文、运行数据库、密钥、模型权重或测试输出。更新时保留自己的 `data`，重启服务并刷新浏览器，无需重新导入论文。

## 常见问题

| 问题 | 排查方式 |
| --- | --- |
| 双击后无法启动 | 检查 Node.js 版本和依赖安装，查看启动窗口报错；不要删除 data |
| 更新后仍是旧界面 | 停止旧服务，启动新版，浏览器 Ctrl+F5 |
| 全文翻译限流／额度不足 | 检查当前选中的服务与账户额度，降低并行或稍后继续；已完成译文保留 |
| 本机模型连接失败 | 确认 Ollama 已启动、模型已下载；11434 是模型服务，3089 是阅读软件 |
| GPT／DeepL 鉴权失败 | 核对各自密钥、地址／套餐与权限，保存后用连接测试验证 |
| 查词有中文，但补充例句失败 | 本地词典和在线例句翻译互相独立；查看补充结果的错误原因 |
| 音标存在但没有声音 | 检查系统英文语音、浏览器和音量；音标库不包含所有词的音频 |
| PDF 无法选中文字 | 扫描件先 OCR；复杂文字层、公式和双栏仍可能提取不完整 |

## 技术结构

前端采用原生 JavaScript、HTML、CSS；后端使用 Node.js HTTP 与 SQLite；PDF.js 负责本地提取及浏览器渲染。没有必须运行的云端后端。

```text
PaperLex/
├── server.mjs                 # 本地服务、数据与接口
├── launcher.mjs              # Windows 启动与依赖检查
├── translation.mjs           # 全文翻译任务与译稿保存
├── deepl.mjs                 # DeepL API 与缓存
├── online-translation.mjs    # MyMemory 队列与缓存
├── lookup.mjs / research.mjs # 查词、科研语境与术语
├── corpus.mjs                # 论文搜索与开放正文
├── memory.mjs                # 记忆曲线与复习调度
├── pdf-paragraphs.mjs         # PDF 段落及双栏分析
├── public/                   # 阅读器、词汇库、翻译编辑器
├── resources/                # 本地词典、音标及来源许可
├── docs/                     # 详细使用指南
├── scripts/                  # 文档与资源维护脚本
└── tests/                    # 单元、接口与浏览器检查
```

`PORT` 和 `PAPERLEX_DATA` 环境变量可分别指定端口与数据目录。旧版原位排版实验组件仍保留在源码中；当前自动排版原页对照与浏览器 PDF 导出不需要额外 Python 组件。

## 开发与验证

```sh
npm ci
npm test
node scripts/build-guide.mjs
```

`npm test` 使用隔离临时数据，覆盖查词、PDF 分段、锚点、复习调度、翻译任务、缓存及接口。浏览器回归：

```sh
node tests/browser-smoke.mjs
```

浏览器脚本当前使用 Windows 默认路径的 Google Chrome；其他环境需调整脚本中的浏览器路径。在线模型通过模拟服务验证，不代表已验证个人账户额度或实际翻译质量。

详细指南源文件为 `docs/使用指南.md`，运行构建脚本生成根目录 `详细使用说明.html`，供应用内和离线阅读。

欢迎提交 Issue 或 Pull Request。复现问题时请描述系统、Node.js 版本、操作步骤和已脱敏的错误；不要提交 API 密钥、数据库或无权公开的论文。

## 已知限制

- 不含 OCR；双栏、公式、表格和特殊字体可能影响段落识别与源文定位。
- 批注保存在应用数据库，不直接写回原 PDF。
- 自动翻译及概要需要对照原文核验；不保证专业术语、复杂句法或长文信息完整。
- 开放正文读取只覆盖支持的来源，不绕过付费墙或来源权限。
- 外部服务的可用性、额度和费用由提供方控制。
