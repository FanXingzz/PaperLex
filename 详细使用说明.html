PaperLex · 详细使用说明

支持 PDF 阅读、语境查词、批注、全文翻译与词汇复习。

源码仓库：FanXingzz/PaperLex。首次从仓库下载时请保留完整目录结构，双击启动脚本会按需安装依赖。仓库不包含个人论文、数据库、密钥或模型。

这是在自己电脑上运行、通过浏览器操作的科研文献阅读软件。浏览器只是操作窗口；文献、笔记和学习记录保存在电脑上的 data 文件夹。打开本地地址不等于把文献上传到网站。

第一次使用建议走这条路线：启动 → 新建项目 → 开启普通联网 → 导入一篇论文 → 选词查询 → 收藏 → 复习。无需先安装模型，也无需先填写任何密钥。

1. 正确启动、关闭和更新

1. 打开 解压后的 PaperLex 文件夹，双击 启动.bat。

2. 启动窗口会打印中文提示，并自动打开默认浏览器。正常情况下进入 http://127.0.0.1:3089。若该端口被其他程序占用，会使用后续端口，以窗口实际显示为准。

3. 如果浏览器没有自动打开，把窗口中的完整地址复制到浏览器顶部地址栏，再按回车。不要把地址放进搜索框。

4. 使用期间保留最初的启动窗口，可最小化。仅关闭网页不会停止软件；下次可重新访问同一地址。

5. 结束使用时关闭启动窗口，或在窗口中按 Ctrl+C。再次使用时重新双击脚本即可。

6. 如果重复双击，启动器会尝试打开同一数据目录已经运行的新版软件，不会重复启动它。

当前版本修复了什么：原脚本含中文内容、采用 LF 换行，在你的 Windows 命令窗口中出现乱码和命令截断。现改为纯 ASCII 的短批处理入口、Windows CRLF 换行，中文提示由 Node.js 启动器输出，并自动打开浏览器。

更新后仍看到旧界面：关闭之前运行软件的终端窗口，再运行新版 启动.bat，在网页中按 Ctrl+F5。不要删除 data，也不需要重新导入文献。当前版本两种阅读模式的更新作用于已有文献。

需要 Node.js 22.13 或更高版本。本地已安装依赖时，可断网启动；如果依赖缺失，首次安装 PDF 组件需要联网。启动环境安装与软件内的“联网服务”开关是两件事。

软件左下角“使用指南”可打开本教程；软件没启动时，也可直接双击同目录的 详细使用说明.html 阅读，教程本身不需要联网。

3. 普通联网：最简单的配置方法

1. 确保电脑可以正常上网，启动软件。

2. 点击左下角 设置与数据。窗口较窄时，它是左侧齿轮图标。

3. 勾选 启用联网翻译与科研语料检索。

4. OpenAlex API Key（可选）先留空。它用于科研论文检索，不用于普通翻译。

5. 不要勾选“启用模型增强释义与双语概要”。下面的服务地址、模型名称和模型 API Key 保持原样即可，它们在此模式不会使用。

6. 不要勾选“清除已保存的全部密钥”。点击窗口底部 保存设置。

7. 右上角应显示 联网服务已启用。进入一篇文献，在右侧输入 electric field，点击 查询释义。

8. “electric field”已被内置科研词库收录，显示“电场”不能单独证明联网成功。进一步选择“句子：翻译完整句子”，输入 The electric field increases during the discharge.，成功时可见全句译文及 MyMemory 来源。检查结果下方是否有错误信息。

各在线服务分工：MyMemory 翻译词句、词典英文释义与摘录；Free Dictionary API 提供英文义项、音标及可用发音；三种论文引擎提供科研论文元数据与可用摘要。一项失败不代表另一项一定失败。网络环境、服务额度及接口要求都会影响可用性。

3.1 联网查词和长句翻译

1. 打开文献，把鼠标放在中间原文区域，拖选同一页内的英文词、短语或句子。

2. 点击浮动工具条里的 查词 / 翻译。也可直接在右侧输入框粘贴英文，再点击 查询释义。

3. 右侧释义框可手动修改。专业术语有歧义时，应根据课题核对、补充。

4. 点击 收藏并加入复习，会保存所选文本、释义、来源页和上下文。同一项目中再次收藏相同词条会更新内容，而不是再建一个重复条目。

当前版本词语结果分为：读音与音标、当前语境释义、不同义项的中英文解释、对应双语例句，以及本地和联网论文例句。内置科研词条按原句与课题线索排列义项，例如 plasma 的等离子体 / 血浆、quenching 的猝灭 / 淬火。每张义项卡都会标注来源；教学例句不是论文引文。

查询先显示本地或缓存结果，再独立补充联网／模型释义。需要更完整的通用义项时，点击“补充通用词典的多义项与例句”，系统先查询 Free Dictionary API，连接失败时使用本地 WordNet 3.1，再翻译可用释义及例句。最多展示 4 条在线词典义项；词典缺少例句时明确显示缺失，音标优先查本地库，不编造。外部词典是通用英文词典，不能覆盖全部科研词汇。联网后查询词会发送给该词典，播放词典音频时浏览器会访问音频来源。

点击“读音”或“例句读音”可朗读英文，优先使用可用的系统英文语音；联网且系统无合适语音时尝试词典音频。离线只使用本地语音。若没有声音，检查音量与 Windows 已安装的英文语音；音标可见不代表电脑必然已安装发音资源。

查询输入框下可手动选择“词语”或“句子”。句子模式显示全句翻译，不会把每个词拆成词卡。自动识别有局限，短句误判时手动切换即可。单次最多 4000 字符，较长内容建议分句；跨页请分段选取。

普通翻译已增加科研术语约束，但仍是通用翻译引擎，不能保证复杂句法和专业歧义完全准确；有兼容模型时启用模型增强，可同时利用原句、研究方向、术语表和本地例句生成解释。

3.4 校正项目专用术语，让后续翻译保持一致

在词语结果下展开“校正为本项目的专业译法”，填写简短译法，例如 quenching → 猝灭，点击保存。后续同项目查词优先展示该译法；模型整句翻译会收到这些术语约束。普通翻译先翻译完整英文句子，再把可识别的中文译词校正为项目指定译法，以保留句子语序。不能自动识别的译词仍需人工核对；请只填写术语，不要填整段解释。

在“我的词汇库 → 项目专用术语”中可以查看或删除校正。它与用于复习的收藏词条相互独立，删除一个不会自动删除另一个。术语表随数据备份与 JSON 导出保存。

3.2 查找课题相关论文里的例句

1. 新建项目时，在研究方向栏填简洁英文关键词，例如 plasma electric field diagnostics。不填时仅按查询词搜索。

2. 在阅读页查一个词，例如 electric field 或 quenching。

3. 点击右侧 联网论文语料，选择引擎，点击 检索科研论文。论文检索独立发起，不拖慢查词。

4. 系统显示检索条件、论文标题、年份、来源链接，以及公开摘要中确实包含该词的句子。点击标题可去论文来源网页。

5. 若论文有“检索开放全文正文”按钮，点击后会下载可读取正文，显示匹配句及章节／页码。正文与摘要明确分开；其他论文可下载开放 PDF 后导入本地库检索。

检索以项目方向辅助匹配，不是对课题的深度自动理解；也不是无限制全文下载器。当前界面尚无项目重命名 / 编辑方向入口，方向填写不合适时可另建项目并重新导入所需文献。

如果论文检索提示认证或额度问题，可在 OpenAlex 官方页面登录，按其账户页面指引获取个人 API Key，再填入设置对应框。已有密钥时，密码框留空保存会保留旧密钥。密钥和额度要求以 官方认证说明为准。

3.3 获得中英文概要

1. 先开启联网并保存，再导入文献：程序自动摘取英文关键句，再翻译为中文。

2. 如果文献早已在离线状态下导入，打开它，在右侧 文献双语概要 中点击 重新生成。仅切换联网开关不会批量重做以前的概要。

3. 等待状态从“正在生成…”变为“双语概要已就绪”。通过 中文概要 / English 切换语言。

4. 右侧内容较多时，把鼠标移到右侧栏内滚动，概要可能位于查词和例句下方。

5. 如果出现“译文待重试”，查看错误原因，恢复网络或等待额度恢复后再点击重新生成。

普通联网模式是“原文摘录 + 中文翻译”，不是逐项分析整篇论文。更详细的研究问题、方法、发现和局限概要需要配置模型。模型也只接收前 26000 字符，长文后半部分的信息可能遗漏。

4. 完全离线怎么用

1. 打开设置，取消勾选“启用联网翻译与科研语料检索”和“启用模型增强释义与双语概要”，保存。

2. 新建项目，导入文献，阅读原文、滚动页面、批注，均不需要网络。

3. 输入词汇后点 本地关联，可找出项目内含此词的句子。勾选 检索整个本地文献库 可跨项目查找。

4. “词形匹配”尝试识别常见变化，例如 field / fields；“精确匹配”只匹配原词形、不区分大小写。短语必须在一个完整句子中按顺序出现。

5. 点击例句的 回到原文 跳到对应文献页。离线无模型时，“解释此句”无法生成新的译文；原文例句仍可看。

6. 内置 ECDICT 英汉词典约 76.9 万词条，并有少量按科研语境整理的术语、多义项和双语教学例句。未收录专业词可手填释义或配置本地模型。

7. 已收藏词汇、已生成的中文概要、批注和复习计划仍能离线查看。没有收藏的在线查询结果和论文检索结果不构成永久离线缓存。

关闭联网开关不会删除以前的中文概要，也不会把数据库清空。纯离线导入的新文献只有英文摘录，中文待生成是预期状态。

5. 本机模型使用说明（Windows，从安装开始）

PaperLex 是阅读软件，Ollama 是运行模型的程序，qwen2.5:7b 是需要另行下载的模型。只填写模型名称不会安装或启动它。联网翻译不需要完成本节；本节沿用软件当前配置的模型作为示例，不代表它最适合所有电脑。

第一步：安装并启动 Ollama

1. 打开 Ollama Windows 官方下载页，下载并安装。

2. 安装后从 Windows 开始菜单打开 Ollama，让它保持后台运行。再重新打开 PowerShell（Windows 搜索框输入 PowerShell 即可）。

3. 输入下面命令并按回车；能看到版本号表示命令可用。如果提示找不到命令，先重开终端，仍不行再检查安装。Windows 官方说明

ollama --version

第二步：下载并确认模型

首次下载需要联网，等待进度结束。预留模型磁盘空间；翻译速度取决于内存、显卡和模型大小。输入：

ollama pull qwen2.5:7b
ollama ls

第二条命令列出已下载模型，确认出现 qwen2.5:7b。只有下载成功后才继续。可以先用一条示例句测试并预热模型：

ollama run qwen2.5:7b "Translate into Chinese: The plasma density increases."

出现中文回答，表示服务和该模型都能工作。首次载入可能比后续慢；测试完成可以关闭聊天终端，但保持 Ollama 后台程序运行。官方命令说明、示例模型页面

第三步：填写 PaperLex 设置

打开左下角“设置与数据”，逐项填写并保存：

设置项本机模型应填写的值
启用模型增强释义与双语概要勾选
服务地址http://127.0.0.1:11434/v1
模型名称qwen2.5:7b，必须与 ollama ls 中的名称完全一致
模型 API Key本机 Ollama 留空；以前填写过远程密钥时先清除
启用联网翻译与科研语料检索纯本机翻译可关闭；需要联网查论文或 MyMemory 时开启
OpenAlex API Key与本机模型无关

11434 是模型服务，3089 是 PaperLex 网页，不能互换。服务地址保留 /v1，不要添加 /chat/completions，软件会补上。这个本地接口地址依据 Ollama 官方兼容接口说明。

第四步：在论文里使用

1. 先查询一句短句，检查能否得到模型解释。

2. 打开“全文翻译与编辑”，在“翻译来源”选择“GPT / 已配置模型”。

3. 本机初次使用先把“同时翻译”设为 1 段，再点“开始／继续全文翻译”。运行稳定后可以尝试 2 段；不保证并行一定更快。

4. 已完成段落会保留。单段出错可选中它，再点“重试所选失败段”。

5. 下载完成并使用本地模型时，可以关闭软件的联网开关进行本机翻译。重新开机后先启动 Ollama，再启动 PaperLex，不必每次重新下载模型。

全文模型每次请求最多等待 90 秒；一般查词模型请求约 45 秒。PaperLex 不会自动安装模型，也没有实际测量你电脑运行 qwen2.5:7b 的速度。启动和模型管理命令参见 Ollama CLI 官方文档。

不想运行本机模型：直接联网翻译

在设置开启“启用联网翻译与科研语料检索”并保存。回到全文翻译窗口，在“翻译来源”选择 MyMemory 联网翻译 · 无需模型，点击开始／继续。即使全局模型增强仍开启，这次全文翻译也不会调用本机模型。

MyMemory 不需要模型密钥，但会收到待译论文文字，有免费额度和服务限流，科研译法需要校对。若有远程 AI 服务，在设置填写对应服务地址、模型名和密钥，再选择“已配置模型”。切换来源前先暂停并等待在途请求结束。已完成译文不会自动覆盖。

6. 远程模型与混合模式（进阶，可跳过）

如果你已有支持 Chat Completions 格式的远程模型服务，可同时勾选联网与模型增强，并填写服务方提供的基础地址、实际模型名称和 API Key。地址不是网页聊天地址。软件不提供模型账号或额度，费用由服务方决定。

启用模型增强后，查词和概要优先使用模型。词句查询遇到模型失败时，会明确提示并尝试内置词条或联网基础翻译；未联网时不能回退到在线服务。文献概要的模型任务失败仍需修复配置后点击重新生成。想固定使用普通翻译，可取消模型增强、保持联网开启并保存。

同时开启联网 + 本地模型时，词句解释和概要由本地模型完成，论文检索仍联网访问所选引擎。开启联网 + 远程模型时，所选上下文和用于概要的文献片段会发送到该远程模型。

7. 项目、导入、连续滚动与批注

7.1 建项目并导入

点击“新建项目”，名称可以写“低温等离子体电场诊断”，研究方向建议用简短英文。创建后选择左侧项目，再点击“导入文献”，或把文件拖到文献列表区域。处于“全部文献”且有多个项目时，要先选择导入目标项目。

支持 PDF、UTF-8 TXT 和 Markdown，可一次多选；单文件最大 50 MB，PDF 最多 1000 页。同一项目内按文件内容去重，改文件名不会绕过去重。软件复制文件到自己的数据目录，不修改外部原件。导入时文件名去掉扩展名作为文献标题。

7.2 翻页模式与连续滚动：可以自由切换

PDF 文献打开后直接显示原版图文，不再提供文本精读切换。下面的“阅读方式”支持翻页模式／连续滚动，切换保留当前页。TXT/Markdown 保留普通原文阅读。

翻页模式：每次只显示一页，通过顶部上一页 / 下一页按钮切换。滚轮只在当前页面内移动，不会直接切到下一页。适合对照版式、逐页精读。

连续滚动：把鼠标放到中间原文区域，滚动鼠标滚轮或触控板，即可从第一页连续读到后续页。每页之间有页码分隔，顶部页码随滚动更新。适合顺着全文阅读。

初次默认为连续滚动；你选过“翻页模式”后，同一浏览器、同一本地地址会记住偏好。重启软件后一般不用重新选，清理浏览器站点数据、换浏览器或换端口可能重置偏好。

  • PDF 原版：保留原始版式；连续模式靠近可视区域时逐步加载，长文不会一次渲染全部画布。
  • 上一页 / 下一页：两种阅读方式都可用；翻页模式切换页面，连续模式直接滚动到相邻页。
  • 在两种模式之间切换，会定位到当前页。批注和例句的“回到原文”也会定位到对应页。
  • 如果滚动的是右侧释义栏，移动的是右侧内容；请把鼠标移到中间论文上再滚动。
  • 跨页选区暂不支持直接批注或查询，请在同一页内分段选择。

7.3 批注与收藏是两回事

拖选同一页中的原文 → 点击“批注” → 填笔记 → 保存。批注显示红色下划线，悬停可看笔记；在右侧“阅读批注”可回到页码或删除。所有项目词汇库中的完整词／短语，在论文中显示黄色荧光底色（忽略大小写），悬停可看收藏释义。PDF 选区按页内坐标保存，换行、连字符和双栏提取顺序不一致不会阻止批注；扫描图片需先 OCR 才能选中文字。批注与词汇保存在软件数据库，不写回 PDF 原件。

“保存释义到词汇库”同时收藏词条，并记录当前 PDF 选区与来源页。词汇库点击“原文”会打开 PDF，滚动并高亮收藏位置；以后修改释义不会替换最初来源。旧词条缺少坐标时按已有上下文查找，无法准确匹配时只打开来源页。

7.4 原文缩放与右栏字号

原文顶部有“− / 百分比 / ＋ / 重置”，范围为 50%–200%；鼠标放在原文内，按住 Ctrl 滚动也可调整。PDF 按比例重新渲染，放大后可在中间阅读器内横向滚动。重置恢复 100%（PDF 适合当前阅读宽度）。

右栏顶部有独立的“右栏字号 A− / A＋”，范围 12–22px。调整影响释义、例句、概要和批注，不会同时缩放原文。两个设置在当前浏览器中保存。

7.5 从其他页面回到正在读的论文

左侧“继续阅读”按钮显示最近打开的文献与页码。从词汇库、复习页或其他项目切走后，点击它即可返回最近文件。软件记录页码、页内相对位置及文本 / PDF 显示方式；刷新页面后也可使用该入口，不必重新找文件。

阅读位置保存在当前浏览器的本地存储，最多保留最近 30 篇记录；切换浏览器、清理站点数据或使用不同端口可能看不到原阅读进度。文献、批注和词汇仍保存在数据库，不受此影响。该按钮指向最近打开的文献，不是无限历史后退。

7.6 双栏分段与旧文献优化

全文译稿先识别栏间空隙，再按各栏合并文字行与段落，支持窄栏间距和非居中双栏。点击译文时按原段的每行文字高亮，避免矩形跨栏覆盖。复杂表格、公式穿插和跨栏段落仍需结合原图核对。旧 PDF 译稿打开后自动重建分段：能对应的译文保留，无法匹配的已译内容显示在顶部“旧译文待核对”，并保存在 JSON 中；新段落可继续翻译或手动校对。

已有 PDF 可在阅读页顶部点击“优化文字提取”，按新版方式重新解析。可以唯一匹配的批注会迁移到新位置；有重复选区或无法匹配的页保留旧文本，并提示页码。不会修改 PDF 原件，也不会删除笔记。复杂表格、公式、跨栏插图及扫描件仍需结合 PDF 原版核对；此功能不是 OCR，也不保证自动还原全部版面。

8. 词汇库与记忆复习

1. 阅读时查询或手填释义，点击收藏。没有释义的词条不能保存。

2. 左侧“我的词汇库”可以按单词或中文搜索，编辑释义，删除词条，点击“原文”返回出处。显示范围与所选项目有关，选“全部文献”后可查看全部项目词条。

3. 点击“今日复习”，先看词和原句，尝试回忆；按空格或点“显示释义”翻卡。

4. 自评“忘记了 / 有点难 / 记住了 / 很熟悉”，快捷键分别为 1 / 2 / 3 / 4。

5. 新词立即进入待复习队列。忘记后约 10 分钟再次到期；首次记住后约 1 天、下一次约 3 天；首次很熟悉约 4 天。后续随历史自评调整。

6. “当前没有到期词汇”可能只是下一次复习尚未到，不代表词汇被删除。应用关闭期间不会弹出系统复习提醒，打开后再查看队列即可。

“今日复习”顶部有遗忘曲线及目标记忆率，可选择 80%、85%、90%、95%、97%。默认 90%，以上初始间隔对应此默认值。提高目标会缩短间隔，并重新安排已有词汇；忘记的词仍在 10 分钟后复习。曲线采用指数模型 R(t)=0.9^(t/S)，S 随自评与历史遗忘调整。它是计划估计，不是实测记忆率，也不是 FSRS。旧记录保留，并从原间隔估算初始状态。

9. 常见问题排查

点击批注返回原文与删除确认

在文献右侧的批注列表中，直接点击批注文字或“回到原文”，阅读器会切换到所在页、滚动到对应文字，并用橙色边框提示位置。翻页和连续滚动都支持；始终在 PDF 内定位，不切换为纯文字。批注仍以红色下划线显示。

删除词汇或批注时，确认窗口居中显示。点击“确认删除”才执行；“取消”、Esc 或点击窗口外均保留数据。

释义修改后如何保存

在右侧“当前语境释义”框修改或补充内容后，点击紧邻下方的 保存释义到词汇库；已收藏的单词显示 保存释义修改。看到“已保存到本项目词汇库”才表示保存成功，仅在输入框打字不会自动保存。

再次查询同一单词时（不区分英文大小写），本项目已保存释义优先显示，联网结果及补充词典不会自动覆盖它。关闭软件再打开也会保留。词汇库中点击“编辑”保存的内容同样生效；更新已有词条不会重置复习进度。不同研究项目分别保存各自释义，适用于课题之间含义不同的情况。

该保存同时收藏词条并加入复习。完整语境说明可以较长；“保存项目术语”用于简短的专业译法，供整句翻译使用，两者用途不同。

新增：全文翻译、编辑及本地导出

1. 打开一篇已导入论文，点击顶部 全文翻译与编辑，会打开独立编辑窗口，保留原阅读窗口。

2. 联网翻译：在主窗口的设置开启“联网服务”。有模型时再启用模型增强并填写实际可用的地址、模型名和密钥；未配置模型时使用基础翻译，长论文容易达到免费额度。

3. 离线翻译：先安装并运行本地模型，按本文“本地模型”部分设置地址和模型名，开启模型增强，保持联网服务关闭。没有本地模型时仍能打开译稿、手动填写与修改译文、保存和导出，但不能自动翻译。

4. 点击 开始 / 继续全文翻译。软件逐段处理整篇可提取文字，不使用概要的 26000 字符上限。右上角显示完成段数；关闭编辑网页不停止后台任务，关闭启动窗口会停止服务。重启后点击继续，已完成和手动修改的段落会保留。

5. 点选右侧译文段落或段落列表，在右侧修改译文，点击 保存此段到本地 或按 Ctrl+S。切换页码时保存当前修改；切换段落或关闭窗口遇到未保存修改会提示。

6. 暂停停止安排后续段落，正在请求的一段可能仍完成。临时网络错误自动重试最多两次；单段失败会记录原因并继续其他段落。连接被拒绝、鉴权失败或限流／额度问题会暂停，修复服务后点继续。可选择失败段后点击“重试所选失败段”。

7. 点击右侧译文段落，左侧原页高亮对应原段；点击另一段时，上一处高亮自动清除。按段落关联，不会假定译文句子与英文句子逐字对齐。勾选“此块保留原文”可以保留公式或参考文献文字。

8. 保存版式译文 HTML：下载包含原页图像和完整自动排版译文的单文件，断网后双击可读。译文可搜索和复制；未翻译段落明确标示。

9. 保存可编辑译稿 JSON：保存原文、译文、每块坐标和字号等数据，便于备份或外部处理。目前没有 JSON 导入入口；继续在 PaperLex 编辑请重新打开同一篇论文的全文翻译窗口，完整迁移请备份 data 文件夹。

10. 导出 PDF（打印）：允许浏览器弹出窗口，在打印目标选“另存为 PDF”，关闭页眉页脚，并使用实际大小／100% 缩放。也可先导出 HTML，再打开打印。纸张尺寸按打印设置选择，译文自动换行分页，请核对打印预览。

全文翻译现在仅保留“自动排版 · 原页对照”，已有译稿自动使用此方式，不需重新翻译。左侧展示原页，右侧译文自动换行和扩展高度；导出按原页参考图与完整译文依次排列。复杂公式、表格和扫描文字仍需核对，扫描件请先 OCR。TXT/Markdown 左侧显示提取原文。原文件不会被改写；无需安装额外 PDF 排版组件。

新增：选择论文引擎、获取正文例句

操作入口是阅读页右栏 联网论文语料。选择引擎，点击“检索科研论文”；有结果后，再点击某篇论文的“检索开放全文正文”。不需要掌握 API 用法。

阅读工具区与音标更新

阅读器页码工具条上新增“收起顶部”，可以隐藏文献标题、原文件入口、全文翻译和文字提取按钮，释放阅读高度；点击“展开顶部”恢复，选择自动记住。

音标库随软件保存在本地，包含约 12.5 万美式和 6.5 万英式词条（两者有重叠），例如 measurement 无需联网即可显示。音标来自 ipa-dict，已保留原许可证和来源版本。它只扩充音标，不等于同等规模的离线释义词典；未收录词仍需联网或使用系统朗读。

查词速度与音标排查

  • 查询先显示内置／项目术语或缓存，再独立请求联网／模型解释；增强过程中仍可编辑、收藏。你开始编辑后，增强结果不会自动替换你的输入。
  • 音标请求与释义独立：内置词音标即时返回，外部词典请求最多约 3 秒，失败显示“暂不可用”，不会一直转圈；重复失败短暂缓存 5 分钟，成功词典响应缓存一天（重启清空）。同一词的并发词典请求会合并。
  • 需要更多义项和成对例句时，点击 补充通用词典的多义项与例句。该步骤还需翻译英文解释，因此可能比基础词义慢。按钮会显示加载状态；未收录、服务不可达或翻译失败会显示具体原因，已有词义不会被清空。在线词典不可达时会自动回退本地 WordNet；它提供英文义项及部分例句，中文解释仍需联网翻译。即使已有内置科研词义，也会尝试补充通用词典义项。模型解释本身取决于模型速度，最多等候约 45 秒；先显示的本地结果不受影响。
  • 音标是文字；读音是声音。没有词典音标也可以用系统英文语音朗读。Windows 设置 → 时间和语言 → 语音，添加英文语音，重启浏览器再试。系统没有可用语音时才尝试词典音频，音频约 4 秒超时后提示失败。
  • 外部词典未收录的缩写、复合专业名词不生成猜测音标；可用模型解释、项目术语或手动补充词义。

PDF 文本顺序乱、公式不完整切换 PDF 原版核对；多栏、表格、公式提取可能不准确

右侧看不到概要 / 批注在右侧栏内部向下滚动，联网例句可能占据较长区域

MyMemory 有字符和调用额度限制；具体以 官方额度说明为准。可在设置填写自己的真实联系邮箱；仍受服务方额度限制。论文检索、翻译、远程模型可能适用不同额度。

10. 数据保存在何处、怎样备份

所有项目、文献解析文本、笔记、词汇、复习记录、概要和设置保存在 软件目录下的 data。原文件副本位于其中的 files 子目录，数据库为 paperlex.sqlite。

完整备份：停止软件 → 复制整个 data 文件夹到安全位置。迁移电脑时，目标电脑需有运行环境和软件文件，再在软件关闭状态下放回完整数据文件夹。恢复会使用备份的数据，不会自动与另一份数据合并；先保存目标端现有数据副本。

“设置与数据 → 导出学习数据”得到可读 JSON，包含学习记录和提取文字，不含 PDF 二进制与密钥。当前没有导入 JSON 恢复按钮，因此它不能代替完整 data 备份。不要删除 data 来处理启动问题，不要只拷贝运行中的单个 SQLite 文件。

纯离线时，不向上述翻译或论文服务发出请求。普通联网会发送查词内容、自动摘录和检索关键词；远程模型会接收所选上下文和用于概要的文献片段。原 PDF 文件不会直接上传。应用不嵌入远程页面，点击论文来源链接会在浏览器访问外部网站。

11. 定位、显示与翻译故障处理

原文显示与翻译故障处理

返回原文时，高亮会去除重复选区，不叠加框线遮挡字形。批注按每行显示一条红色下划线，新旧批注都使用同一种显示。

全文翻译左侧有“整页”“适合宽度”和缩放按钮，默认整页显示；放大后在左侧原页内独立上下、左右滚动，能查看页底和另一栏。点击译文仍会定位原段。

“同时翻译”可选 2 段或 1 段；本机模型卡顿时选 1 段。完成的段落不重译，重复原段在当前版本任务复用结果，基础翻译缓存已成功的小段。具体速度取决于模型、硬件和服务限流，并行不保证速度翻倍。全文模型请求最长等待 90 秒，临时故障有两次延迟重试。

若显示“请启动本机模型”，检查设置中的服务地址与模型名。本机地址 http://127.0.0.1:11434 对应常见的 Ollama 服务；需要先安装并启动 Ollama、准备设置中指定的模型（例如 qwen2.5:7b）。仅在设置填写地址和名称不会安装或启动模型。也可在设置改用已可用的远程模型；关闭模型增强并保持联网开启会使用基础翻译，但科研译法和免费额度有限。软件不会在本机模型失败时自行把整篇论文切换到其他服务。

收藏原文定位与完整语境

词汇库点击“原文”后，滚动到收藏位置，只保留收藏词的黄色标记，不给整个语境段落加色。新收藏根据 PDF 选区所在原段及句子边界保存完整语境，不再截取固定字数；进入词汇库时会尝试从仍在本地的原文补全旧记录。原文缺失或提取不完整时保留原有内容，不编造缺失文字。

GPT、DeepL 与每日全文翻译（新增）

MyMemory 免费公共额度较少，建议仅作偶尔查句备用。GPT 与 DeepL 使用你自己的 API 账号，各自受服务商额度、费用和网络可达性限制，不是无限免费翻译。服务之间不会自动切换；已完成译文与手工修改会保留，剩余段落按新选择的服务继续。

使用 GPT

1. 打开左下角“设置与数据”，在“模型预设”选择 OpenAI GPT。

2. 软件自动填写服务地址 https://api.openai.com/v1 和示例模型 gpt-4.1-mini。模型名称可改为你的账号可用且支持 Chat Completions 的文本模型。

3. 在模型 API Key 中填写你自己的 OpenAI API 密钥，确认启用联网与模型增强，点击“保存设置”。密钥只在软件内填写，不要发到聊天中。

4. 再打开设置，点击“测试已保存的模型连接”。此操作只发送一句内置英文示例；成功会显示中文译文。

5. 打开论文的“全文翻译与编辑”，翻译来源选择 GPT / 已配置模型，点击“开始 / 继续全文翻译”。初次可选同时翻译 1 段。

6. 自己的兼容服务可选“自定义远程 / 本机模型”，填写供应商提供的地址、模型名和密钥。地址更换到不同服务器时，旧密钥不会被自动沿用，需要填写对应密钥。

这是 OpenAI API 接入，需要可用的 API 密钥与 API 额度；软件不使用浏览器里的 ChatGPT 登录会话。本机模型仍按《本机模型使用说明》配置。

官方说明：GPT-4.1 mini 支持接口、创建 OpenAI API 密钥。

使用 DeepL

1. 准备 DeepL API 账号与 API 密钥，普通网页翻译订阅不能代替 API 密钥。

2. 打开“设置与数据”，开启联网，在“DeepL 全文翻译”里选择自己账号对应的 API Free 或 API Pro，粘贴 DeepL API Key。

3. 点击保存，再打开设置，点击“测试已保存的 DeepL 连接”。套餐选错可能导致鉴权失败。

4. 在全文翻译页面选择 DeepL API · 联网翻译，点击开始。无需安装本机模型，也无需启用模型增强。

5. DeepL 按段接收论文英文，并接收研究方向与标题作为上下文；不上传原 PDF。结果保存在本机，可逐段校对保存与导出。相同内容有本地缓存，避免重复请求。

DeepL API Free 官方当前每月额度为 500,000 字符；大量日常阅读可根据实际用量选择 API Pro。额度耗尽会暂停任务并保留译文，处理账号额度后再继续。官方说明：API 套餐、文本翻译 API。

  • 内置 ECDICT 英汉词典约 76.9 万词条，常见词先显示本地中文释义与音标，不依赖 MyMemory 剩余额度。项目术语和自己保存的释义仍优先。首次载入词典稍需时间，后续查词使用内存缓存。
