把同一课题的文献、术语与阅读笔记放在一起。

用于为联网论文检索补充课题语境；留空时从文献自动提取关键词。

设置与数据

开启后，选中文本与自动摘录概要会发送到 MyMemory 翻译服务；检索词与课题关键词会发送到 OpenAlex。不会上传 PDF 原文件。

填写后会随翻译请求发送给 MyMemory。官方匿名限额 5,000 字符/日，提供有效邮箱通常为 50,000 字符/日，仍有额度限制；留空不发送邮箱。

支持本机 Ollama 等兼容 Chat Completions 的模型服务。远程模型另需开启联网；会发送选中段落，概要最多发送文献前 26000 字符。

DeepL 全文翻译

需单独的 DeepL API 账号；开启联网并保存后，在全文翻译选择 DeepL。仅发送待翻译文字，不上传原 PDF。模型与 DeepL 密钥独立保存。

请先保存设置，再测试连接；测试仅发送一句内置示例。

密钥仅存本机数据库。服务额度与费用以提供方为准。
